Folder / file	What’s inside	Why it’s there
configs/	base_rtdetrv2_r18.yml plus arms/a_ir.yml, a_vis.yml, b_joint.yml, b_ft_ir.yml, b_ft_vis.yml, c_fusion.yml, e00_coco_r18.yml	Training settings. The base file holds everything the arms share: model size, input size, learning rate, augmentation. Each arm file changes only which images that model learns from and what it starts from.
cpp/	src/preproc.cpp, runtime/ (ird_api.cpp, decoder.cpp, runtime_config.cpp), tools/ (ird_build_engine.cpp, ird_infer.cpp), tests/, python/bind_preproc.cpp, CMakeLists.txt	All the C++. It covers the preprocessing that training uses too, the detector library RCI would plug into, the tools that build TensorRT engines and run inference, and the build recipe.
python/ird/	data/ (reading images, preprocessing wrapper, AIRST preparation), train/, infer/, export/, eval/	The Python side: data preparation, training, prediction, ONNX export, and scoring.
scripts/	setup_windows.ps1, train_arms.ps1, export_all.ps1, check_trt_windows.ps1, cpp_windows.ps1, plus .sh versions for Linux and the Jetson	One command per stage, so you never run the Python modules by hand.
tests/	test_preproc.py, test_metrics.py, test_decode_parity.py, make_golden.py, make_synthetic.py, smoke_test.sh	Checks that the C++ and Python copies agree, that our metrics match pycocotools, and a quick end-to-end run on fake data.
setup.py, pyproject.toml	Build recipe for the Python module ird_preproc	pip install . uses these to compile preproc.cpp into a module Python can import, so training uses the C++ preprocessing.
README.md	How to set up and run	Reference.
.gitignore	List of folders Git should not track	Keeps large or generated files out of version control.

Data and downloaded inputs

Folder	What’s inside	Why
data/airst_v0.1s/	airst_train/val/test.json (the split files), duplicates_e10.json, stats.md, e10_label_noise.md, preproc_preview.jpg	Step 1’s output. Every later step reads these JSON files.
data/airst_v0.1s/mini_*, data/airst_sample28.zip	A 28-frame sample	I made it to test the code in my cloud workspace. Training doesn’t use it, and you can delete it.
weights/	rtdetrv2_r18vd_120e_coco_rerun_48.1.pth (81 MB)	The COCO-trained starting point. Every model begins from it.
third_party/RT-DETR/	The official RT-DETRv2 code	The detector we train. We plug into it and don’t change it.
third_party/stb/	stb_image.h	Lets the C++ tool read PNG/JPEG files without OpenCV.

Generated by setup and builds

Folder	What’s inside	Why
.venv/	The Python environment: PyTorch with CUDA, numpy, onnx and the rest	Keeps this project’s packages separate from the rest of your PC. All scripts run .venv\Scripts\python.exe. The stray docs.txt, tests.txt and similar files in it were left by a package install and are harmless.
build/	lib.win-amd64-cpython-312/ird_preproc.cp312-win_amd64.pyd and temporary build files	The compiled C++ preprocessing module (the .pyd is the Windows version of a Python extension). cpp_windows.ps1 will add the CMake build here too: ird_infer.exe, ird_build_engine.exe, ird_runtime.dll.
ird_preproc.egg-info/	Package metadata	Written by pip install .. You can ignore it.
.vscode/settings.json	One line pointing CMake at cpp/	VS Code’s CMake extension needs this.

Generated by training and scoring

Folder	What’s inside	Why
runs/<arm>/s0/	best.pth (best on val, 322 MB), last.pth, log.txt, run_info.json, done.json, eval/, summary/	One folder per trained model. best.pth is the one exported and scored. done.json marks a finished run, summary/ holds training curves you can view in TensorBoard, and eval/ holds per-epoch val scores.
preds/	<arm>_s0_<band>_torch.json (test), ..._val_torch.json (val), .tau.json	Every model’s detections, plus the threshold chosen on val. The TensorRT results will land here as *_trt.json.
reports/	<arm>_s0_<band>_torch.md and .json, compare_ir_torch.md, grid_ir_torch_s0_p*.jpg	Results you read: per-model scores, the arm comparison, and the detection grids.
quick12/	runs/, preds/, reports/ from the first 12-epoch test	The first trial run, kept aside so it doesn’t mix with real results. You can delete it.
